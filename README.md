Superstore Sales Analysis – Power BI

Project Overview

This project focuses on analyzing Superstore sales data using Microsoft Power BI. The dashboard provides insights into sales performance, profitability, product performance, and business trends through interactive visualizations.

Dashboard Pages

Page 1: Sales Analysis

- Total Sales
- Total Profit
- Total Profit Margin
- Total Quantity
- Sales by Category
- Sales by Customer Segment
- Sales by Sub-Category
- Sales by Region
- Sales Trend
- Profit by Category

Page 2: Product Analysis

- Total Orders
- Total Products
- Total Categories
- Total Sub-Categories
- Profit Margin Analysis
- Sales by Product
- Profit by Product
- Sales by Category
- Sales by Sub-Category
- Regional Analysis

Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

Key Features

- Interactive dashboards
- KPI cards
- Sales and profit analysis
- Year-over-year comparisons
- Product performance analysis
- Business insights through visualizations

Project Objective

To transform raw Superstore sales data into meaningful business insights and support data-driven decision-making.
